# Первый аудит готовности Dialoid

Дата: 2026-11-01. Проверка только чтением через Task Tower, без модельного исполнения и без запуска baseline-команд Dialoid.

Проверена локальная основная копия проекта. HEAD на момент аудита: `7066bc0bfa7327a6b7f92dc86b6040aeb90afc2f`.

## Результат

Статус: **blocked**. Ночной режим не допущен, агентное исполнение не проверено.

- `dirty_repository`: имеются незавершённые изменения и неотслеживаемые файлы других задач. Ничего не очищено, не спрятано и не закоммичено инструментом. Нужна чистая отдельная копия выбранной версии для пилота.
- `missing_superpowers`: файл `.agents/skills/superpowers/using-superpowers/SKILL.md` из примера манифеста отсутствует. Это отсутствие по конкретному пути, а не утверждение об отсутствии глобально доступного плагина. Нужно определить поддерживаемый способ подключения и фиксации версии Superpowers для проекта, затем указать действительный проектный путь. Один каталог `.superpowers/` с рабочими артефактами не заменяет навыки.
- Обязательные пути из манифеста существуют. `dotnet` и `codex` доступны как исполняемые команды. Их авторизация, работа модели и тесты проекта не проверялись.
- Baseline-команды не запускались. Отсутствие результата тестов не считается успешным baseline.

Манифест: [examples/dialoid.project.json](../../examples/dialoid.project.json). Он охватывает только тесты ядра; Godot, UI, арт и пользовательские сценарии потребуют собственных проверок. SHA-256 манифеста при аудите: `3d91d4393a37cc1555b8957f00ceed6a97f8be443c2efaa1ed37b2a93c30c2e2`.

## Дальше

1. Подготовить отдельную чистую копию согласованного коммита Dialoid.
2. Определить и зафиксировать подключение Superpowers и необходимые зависимости среды.
3. Запустить применимый baseline с таймаутами и сохранить полноценные доказательства; добавить проверки по области пилотной задачи.
4. Утвердить делегирование согласований, права и бюджеты для реального агентного запуска. Затем проверять полный цикл и сбои; текущий аудит не разрешает ночной автомерж.
