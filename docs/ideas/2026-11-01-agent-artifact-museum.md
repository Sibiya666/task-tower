# Артефакты агентов и музей результатов

Дата: 2026-11-01. Статус: идея владельца; реализация не запрошена.

После завершения задачи показать анимацию создания артефакта по результатам работы агента. Артефакт помещается в музей проекта. Его можно открыть и узнать, что именно создано: описание результата, исходная задача, исполнитель и ссылки на связанные файлы, документы, коммиты или другие материалы.

Не нужна уникальная иконка для каждого результата. Достаточно примерно семи повторяемых групп с общим визуальным образом для каждой группы; конкретное содержимое раскрывается в карточке артефакта.

Предварительные группы для дальнейшего обсуждения:

1. Код и функциональность — механизм/шестерня.
2. Исправление ошибки — починенный щит.
3. Исследование и знания — свиток.
4. Дизайн и визуальные материалы — картина/кристалл.
5. Архитектура и планирование — чертёж.
6. Тестирование и проверка — печать приёмки.
7. Сборка, выпуск и интеграция — сундук/знамя.

Группы — предложение для проработки, не утверждённая классификация. Отдельно определить, появляется ли артефакт после ответа агента, успешной приёмки или попадания результата в main. Не выдавать промежуточную/непроверенную работу за принятый результат. Музей должен ссылаться на существующую библиотеку артефактов, а не создавать вторую независимую копию результата.
