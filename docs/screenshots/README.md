# Скриншоты Task Tower

Три изображения основаны на реальных скриншотах приложения, предоставленных владельцем 1 ноября 2026 года. Нет подставленных имён, статусов или синтетического источника данных.

| Файл | Содержание |
| --- | --- |
| `overview.png` | Две башни проектов. Свет в окнах соответствует активности, высокая башня показана с уменьшением масштаба. |
| `study.png` | Кабинет астролога: два сотрудника, инструмент работы и песочные часы ожидания. |
| `hall.png` | Цельный готический зал с большой командой, общим полом, витражами и свечами. |

`originals/` сохраняет исходные пользовательские скриншоты с белым фоном без изменений. `processed/` — результаты удаления фона через встроенный imagegen. Это обработанные иллюстрации на основе скриншотов, а не неизменённые пиксельные снимки; точную фиксацию приложения представляют originals.

Финальные PNG имеют холст **960×640 (3:2)**, прозрачный alpha-фон, одинаковые поля и пропорциональное масштабирование без растяжения. Скрипт `tools/prepare-doc-screenshots.cjs` воспроизводит нормализацию из processed. `gallery.png` — обзор на тёмной подложке для удобного сравнения; сами отдельные PNG прозрачны.

Промпт обработки (built-in imagegen): remove only the white/light-grey desktop background outside the artwork silhouettes, replace with genuine alpha; preserve foreground composition, architecture, agents, activity icons, colors and proportions; do not add text, borders or new elements. Результаты просмотрены перед включением в документацию.
