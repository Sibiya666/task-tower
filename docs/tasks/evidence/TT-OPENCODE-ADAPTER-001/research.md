## Round 1 review response — draft revision, not acceptance

The [independent R1 review](spec-review.md) rejected the first design for missing absence/membership/environment binding and an unbound stdin open. Its report remains unchanged. All task stages remain pending; R2 review is required.

Additional source checks reinforce the findings: [V2 discovery Sources](https://raw.githubusercontent.com/anomalyco/opencode/v2.2.5/packages/core/src/config/discovery.ts#L12-L23) represents eligible paths that may appear later. [Source-directory discovery](https://raw.githubusercontent.com/anomalyco/opencode/v2.2.5/packages/core/src/plugin/source-directory.ts) inspects direct plugin(s) members, including eligible links. The host must track absent candidates and membership and reject links instead of hashing only previously present files. The proposed bounded collector follows source-qualified eligible names only, not a broad home or credential search; unsupported compatibility/custom/remote sources block.

[V2 startup askpass](https://raw.githubusercontent.com/anomalyco/opencode/v2.2.5/packages/cli/src/index.ts#L32-L35) occurs before ordinary command dispatch. The revised gate rejects inherited askpass/instrumentation/injection selectors before even --version, binds approved policy-affecting environment presence/value digests privately, and keeps pure provider authentication opaque. [Global roots](https://raw.githubusercontent.com/anomalyco/opencode/v2.2.5/packages/util/src/global-roots.ts) uses XDG/home; [global acquisition](https://raw.githubusercontent.com/anomalyco/opencode/v2.2.5/packages/util/src/global.ts#L58-L74) can create runtime directories, while [CLI config](https://raw.githubusercontent.com/anomalyco/opencode/v2.2.5/packages/cli/src/config/config.ts) includes migration infrastructure. Source qualification must account for startup/global effects and concrete actual launch cwd/PWD, not invoke a probe to discover whether those effects occur. No native probe was performed.

R2 builder decisions: host collector records finite discovery closure with explicit missing/file/directory entries, safe filesystem identities, complete direct membership of inspected eligible directories and opaque private environment binding. Distinct qualifier reviews source-audit and counterexample reports; coordinator pins exact policy evidence digest. Before each OpenCode child the host recomputes the actual worktree/ancestor observation and rejects drift. Unknown source surfaces are specific blockers, not positive boolean attestations or owner questionnaires. This is trusted-host immediate-before-launch drift detection, not a filesystem sandbox.

Stdin producer now returns path plus expected digest/size/file identity. Runner copies at most 4194304 bytes into owned anonymous private staging, verifies binding before creating the child, and exposes only staged read bytes. Mutation of the original file after staging cannot change the transport. New deterministic tests cover replacement between producer and runner, in-place mutation while staging, size drift, poststage source replacement, staging failure and handle cleanup. Legacy DEVNULL/result shapes remain unchanged. These are planned tests, not completed implementation evidence.
