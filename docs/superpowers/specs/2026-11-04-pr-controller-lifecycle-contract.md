Its parent supervisor performs no review/publication/merge/closure and cannot impersonate that owner. The child host owns actual PRHostContext/PRSource/PREffects and all journal acknowledgements. Duplicate watch fails before any model/effect. A killed/lost host leaves owned rows/effects/barriers fenced; restarting can inspect but never continue an old owner's mutations. Unowned new tasks can be admitted normally by a new valid watch; old uncertain work remains retained.

It is a diagnostic one-shot, not permission for later fresh processes to take that owner's PR. Document that watch is the command for the full multi-step cycle; a retired one-shot owner cannot be silently resumed. Their read-only/current safety boundaries remain the existing actual journal interfaces.
