## Global Constraints

- Initial candidate contract: current stable OpenCode V2 `2.2.5`, source `9bbb8ce18c80f099e0e448775f59d965ead40a21`.
- No implementation before independent full specification/plan acceptance; no native probe before exact installation-owned executable/config/startup policy acceptance.
- Preserve every legacy Codex/custom schema, argv, capabilities and fingerprint when no new fields exist.
- Generic and stage/role launch dispatch accepts exactly codex/custom; opencode and every unsupported/malformed kind fail before any native child/probe. OpenCode is routed only by the qualified foreground worker branch.
- Exact argv `[EXE, "run", "--standalone", "--format", "json"]`; exact worktree cwd/PWD; no model/agent/variant/auto/server/session flags.
- Full60 unchanged instruction bundle; input maximum 4194304 bytes; result maximum 65536 bytes and UTF-8 summary maximum 4096 bytes.
- Event line maximum 1048576 bytes; count maximum 100000; total stdout maximum 67108864 bytes; normalized evidence maximum 65536 bytes; session/part/message identities maximum 256 characters.
- OpenCode requires log_max_bytes=67108864; reject truncated capture or unknown tail. No live event abort capability is claimed.
- Keep Windows argv below 16000 UTF-16 code units including quoting and POSIX argv below 16384 UTF-8 bytes; preserve current timeout/cancel and five-second cleanup behavior.
- No install/update/auth/session inventory/model selection, credential reads or service autostart; unknown/remote/managed config startup effects remain blocked until qualified.
- Discovery bounds: 64 ancestors; 4096 entries; 256 members per directory; depth 16; 1048576 bytes per nonsecret file; 8388608 total hashed file bytes; 1048576-byte evidence. Include absent candidates, identities, memberships and private policy-environment presence/value binding.
- Frozen stdin is `{path,expected_sha256,expected_bytes,expected_identity}`; verify bounded copied bytes in anonymous private staging before any child, never pass the source handle directly.
- Coordinator owns shared README/AGENTS/roadmap/process docs and Git operations. Separate stage acceptors; head/base/main changes invalidate affected verdicts.

## Review Focus

1. Inherited PWD redirects a V2 session despite cwd: bind both to the exact source worktree (Tasks 1/4).
2. A version probe initializes plugin/config code: reject before invoking without accepted startup evidence (Task 1).
3. V2 reconciliation emits projected text after step_finish: accept same-message projections while rejecting unresolved/new unfinished steps (Task 3).
4. Full60 input or huge private output exceeds Windows transport/storage bounds: use file stdin and reject incomplete stdout; preserve cancellation/cleanup (Tasks 2/3).
5. Policy revocation or uncertain launch tempts recovery replay: status/cancel stay usable and no native session lookup/resume/requeue occurs (Task 4).
